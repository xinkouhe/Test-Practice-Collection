# Selenium 网易云登录探索记录

## 项目定位

这是一个基于 Selenium 的第三方网页登录自动化探索项目。

它的主要价值不是“稳定回归通过”，而是记录以下问题的定位过程：

- `iframe` 切换
- 动态弹窗和分支域名
- 动态渲染导致的 flaky
- 日志、截图和失败证据收集

## 当前保留内容

- 早期单脚本实现
- 基于 `pytest` 的重构尝试
- 负向登录样例数据
- 运行日志和截图
- 从 Playwright 方案迁回 Selenium 的思路笔记

## 能展示的能力

- UI 自动化基础结构
- 对第三方复杂链路的观察与诊断
- 对 flaky 问题的原因分析
- 用日志和截图辅助定位失败

## 当前限制

- 第三方站点有验证码、`iframe` 和多分支域名，天然不稳定
- 该版本不作为稳定回归基线
- 当前更适合作为“探索记录”，不适合作为主展示项目

## 建议阅读方式

- 如果只是快速了解仓库的 UI 自动化能力，优先看 Playwright 版本。
- 如果想看问题定位过程，再看本目录和 `PLAYWRIGHT_TO_SELENIUM_REBUILD_NOTES.md`。
